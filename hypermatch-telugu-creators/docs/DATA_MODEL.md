# HyperMatch data model

**Creator:** stable ID; public identity and bio; specialization; skills; tools/models; content types; output formats; languages and region; portfolio items; workflow; commercial-use terms; profile/source URLs; last-checked date; verification status and claim-specific evidence; explicit demo flag.

**Brief:** ID; brand; campaign title; rough idea; objective; content type; visual style; aspect ratio; platform; language; audience; usage rights; duration; territories; deliverables; deadline; budget; revisions; status; created date.

**Engagement:** ID; creator ID; brief ID; stage; next action; notes; updated date. Stages: shortlisted → brief sent → accepted → in production → revision → delivered.

Verification must be claim-specific. A verified tool claim does not prove workflow quality, past-work ownership, or licensing. Keep evidence and check date for every verified claim.
