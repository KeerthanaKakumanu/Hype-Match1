# 3-minute judge demo

1. **0:00–0:25:** Explain the gap: generic profiles hide AI tools, workflows, output formats, and usage rights.
2. **0:25–1:05:** Search/filter an AI creator; open the profile and show portfolio samples, tool/model tags, workflow, commercial-use notes, and trust signals.
3. **1:05–1:30:** Save a creator to shortlist.
4. **1:30–2:15:** Enter a rough campaign idea in Brief Builder; generate/edit the structured brief; show content type, visual style, aspect ratio, deliverables, and commercial-use requirements.
5. **2:15–2:45:** Add an engagement and move it through production, revision, and delivery.
6. **2:45–3:00:** State honestly that seed profiles are demo personas and that production rollout needs verified source data and shared backend storage.
