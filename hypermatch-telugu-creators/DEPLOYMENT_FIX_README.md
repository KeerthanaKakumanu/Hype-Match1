# HyperMatch — Telugu Creator Marketplace

This folder contains the React + Vite application source and project documentation.

## Deploy to Vercel
- Framework preset: Vite
- Root directory: `hypermatch-telugu-creators` (if this folder is inside a repository root)
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

If you upload the *contents* of this folder directly to the repository root instead, set Vercel Root Directory to `.`. Do not upload only this ZIP file to GitHub.

## Dataset honesty
The included `data/creators.json` currently contains 12 illustrative demo personas, not 500+ independently verified real Telugu creators. Their profile links and performance metrics are not presented as verified. The requested 500+ real-profile directory still requires source-by-source research and verification; do not claim it is complete based on this starter dataset.

## Local run
Install Node.js 18+; run `npm install`, `npm run validate:data`, `npm run dev`.
