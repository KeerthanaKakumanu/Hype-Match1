# Data provenance

Each creator lead in `creators.json` has a source link in the record. This is a starter list assembled from public directory/editorial pages and the My Village Show official site. Social handles are linked as public profile URLs, but links can change; check them before campaign outreach. No follower numbers, email addresses or engagement metrics have been invented.

Public source pages:
- https://www.telanganatribune.com/top-10-influencers-content-creators-from-hyderabad/
- https://socialveins.com/find-influencers/all-all-influencers-in-hyderabad-on-instagram
- https://socialveins.com/find-influencers/all-food-influencers-in-hyderabad-on-instagram
- https://socialveins.com/find-influencers/all-humor_comedy-influencers-in-hyderabad-on-instagram
- https://aveoreach.com/lists/telugu-influencers-india
- https://hobo.video/blog/20-hyderabad-food-influencers-you-should-follow-on-instagram/
- https://www.siasat.com/meet-hyderabads-content-creators-telling-stories-beyond-food-3196835/
- https://www.myvillageshow.in/

Image limitation: profile pictures are resolved from public avatar URLs at runtime, not included as local binaries in this ZIP. The creation environment could not retrieve remote binary assets to bundle and verify.
